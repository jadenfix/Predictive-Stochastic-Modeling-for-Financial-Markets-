# **Predictive Stochastic Modeling for Financial Markets**

## **Introduction**  
Hello! This project is based on my undergraduate thesis, *Predictive Stochastic Modeling for Financial Markets*, which was awarded the **Adam Smith Award** for outstanding economic research. The study explores how financial and macroeconomic variables can enhance the prediction of bear markets in the S&P 500 using **Markov-switching autoregressive models** and **regression-based predictive techniques**.  

By integrating **Bayesian inference**, **time-series econometrics**, and **machine learning-inspired forecasting**, this research provides insights into the dynamics of market downturns, contributing to both academic literature and practical investment strategies.  

📄 **Read the full thesis here:** [Predictive Stochastic Modeling for Financial Markets](https://github.com/jadenfix/Predictive-Stochastic-Modeling-for-Financial-Markets-/blob/main/Predictive%20Stochastic%20Modeling%20for%20Financial%20Markets.pdf)  

---

## **Project Overview**  
This repository contains the full implementation of the predictive modeling framework, including:  

✅ **Bayesian Markov-Switching Autoregressive Models** to estimate bear market probabilities.  
✅ **OLS & Beta Regression-Based Predictive Modeling** for in-sample and out-of-sample testing.  
✅ **Feature Selection & Data Engineering** leveraging key stock market and macroeconomic indicators.  
✅ **Robust Statistical Evaluation** of predictive accuracy across different forecasting horizons.
